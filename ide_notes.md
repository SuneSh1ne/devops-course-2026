# Git в VS Code: заметки

## Что удобно в VS Code

1. **Визуальный diff** — изменения подсвечиваются построчно, сразу видно,
   что добавлено, а что удалено. Не нужно читать вывод `git diff` в терминале.

2. **Разрешение merge-конфликтов** — встроенный редактор с кнопками
   «Accept Current», «Accept Incoming», «Accept Both». В разы быстрее,
   чем править маркеры `<<<<<<<` вручную.

3. **История и blame через GitLens** — наведение на строку показывает
   автора и коммит, можно провалиться в историю файла. Удобно для
   расследования «кто это сломал».

## Что удобнее в терминале

**Interactive rebase (`git rebase -i`)** — в VS Code это делается через
костыли и расширения, а в терминале достаточно открыть редактор,
поменять `pick` на `squash` и сохранить. Полный контроль над историей,
никаких скрытых действий «под капотом».
