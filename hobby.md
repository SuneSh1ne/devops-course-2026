# Мой пет-проект
Идея: еелеграм-бот для учёта личных расходов — пользователь пишет
сумму и категорию, бот сохраняет запись и по команде `/report`
показывает статистику за месяц.
Стек: Python 3.12, aiogram 3, SQLite, Docker
Цель: научиться писать асинхронных ботов, освоить работу с БД
через SQLAlchemy и упаковать проект в Docker-контейнер для деплоя
на VPS.
